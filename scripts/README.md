# Scripts du projet

## Scripts liés au périmètre final V8

Les scripts `create_v8_*`, `reframe_v8_*` et `apply_v8_*` documentent la
construction et les contrôles du framework final. Les scripts
`create_chart_package.py`, `create_recruiter_brief.py`,
`create_llm_engineering_case_study.py` et `create_technical_report_pdf.py`
génèrent les artefacts de présentation publics.

## Scripts historiques

Les autres scripts correspondent principalement aux explorations et pipelines
V3/V4/V7, aux audits intermédiaires ou aux diagnostics. Ils restent présents
pour la provenance et la reproductibilité historique, mais ne définissent pas
les sorties autoritatives actuelles.

Les sorties finales de référence sont dans `data/final/`,
`data/institutional/` et `outputs/`. Le framework autoritatif est V8.11c à
trois cibles ; les anciens scripts ne doivent pas être interprétés comme une
architecture concurrente.
